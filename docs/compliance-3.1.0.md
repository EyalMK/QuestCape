The audit covered the complete production inventory (101 Java files including

review of the actual network, storage, client-capture, publication and cleanup
call paths; searches alone are not proof of correctness.

| Boundary | Finding |
| --- | --- |
| Language and distribution | Java 11 (`options.release=11`, all packaged class major versions 55). No production reflection, native/process APIs, runtime code loading/generation, Java serialization or additional runtime dependency. Tests and test fixtures are excluded from the ordinary JAR; no service-loader/native entries. |
| Client/game access | Current-character quest/real-level/gameval observations run on ClientThread after readiness. Detectors observe only existing completion facts. No game input, chat/server actions, combat/PvP guidance, game widget changes, scene scans or other-player collection. Training purpose prose remains source text, not combat prayer advice generated by the plugin. |
| UI ownership | Own panel and navigation attachment only; no discovery/manipulation of another plugin or core client window. Swing updates use EDT; Ctrl selection and clipboard gestures affect local panel text/URLs only. Search, hint and copy-feedback timers/popups are stopped on disposal/hiding; independent controls retain their own gestures. |
| HTTP/privacy | Injected OkHttp-derived client with bounded bodies/timeouts, cancellation and explicit redirect validation. Blocking calls and classpath metadata preparation run on workers. Fixed Wiki content request and user-triggered allowlisted training verification contain no player identity/progress. The existing Hub third-party IP warning must remain verbatim. No paid-service integration. |
| Local data | Injected Gson; schema/config/account/manual encodings retained. RuneLite-provided plugin Filepath, hashed filenames, bounded JSON and atomic same-directory replacement. java.io types represent streams/exceptions, not arbitrary filesystem APIs. Corrupt originals are retained; pending true/false manual intent and save acknowledgement are revision-aware. |
| Lifecycle/threading | One PluginRun owns bounded workers and cleanup, invalidates authority before cancellation and uses shutdownNow without waiting. ClientThread only captures; serial worker performs persistence; EDT publishes guarded views. Late callbacks retain original run/account authority. No sleeps, latches, blocking lifecycle waits or unowned periodic tasks. |
| Packaging/assets | Entry remains com.questcape.QuestCapePlugin, metadata/version 3.1.0, build=standard and BSD-2 with third-party notices. Icons decode from small packaged images on workers with memory-backed image input. No downloaded guide images or generated artifacts are tracked. Public branding now uses actual sidebar captures. |
